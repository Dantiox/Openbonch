**Openbonch** — полностью бесплатный, открытый и кроссплатформенный клиент для студентов **СПбГУТ им. проф. М.А. Бонч-Бруевича**. 

Разработан как независимая Local-First альтернатива закрытым сервисам (Bonch Go, KarlovBonch) без платных подписок, рекламы и передачи паролей на сторонние серверы.

---

## ✨ Ключевые преимущества

* **100% Бесплатно навсегда:** Никаких подписок «Про», пейволлов «Купить кофе» или заблокированных функций. Весь функционал доступен сразу.
* **Приватность и Local-First:** Ваши логин и пароль от `lk.sut.ru` **НИКОГДА** не отправляются на сторонние серверы. Все запросы идут строго напрямую на официальный домен `lk.sut.ru` с вашего IP.
* **Вход без пароля:** Поддерживается авторизация напрямую по сессионному cookie `miden` из браузера — вам даже не нужно вводить свой постоянный пароль.
* **Умная автоотметка на парах:** Автоматический поиск активной кнопки «Начать занятие» (`open_zan`) и мгновенная отправка подтверждения.
* **Кроссплатформенное ядро:** Ядро `openbonch-core` написано на чистом Rust и готово к интеграции в мобильные интерфейсы (Android / iOS) и десктоп.

## 🚀 Быстрый старт (CLI)

### Сборка и установка из исходников
Требуется установленный тулчейн [Rust](https://rustup.rs/):

```bash
git clone https://github.com/Dantiox/Openbonch.git
cd Openbonch
cargo build --release
```
Исполняемый файл появится в `target/release/openbonch`.

### Команды CLI

#### 1. Авторизация
```bash
# Интерактивный вход по логину и паролю:
openbonch login

# Или вход напрямую по токену miden (без ввода пароля!):
openbonch login --token <ВАШ_MIDEN_COOKIE>
```

#### 2. Проверка статуса сессии
```bash
openbonch status
```

#### 3. Просмотр расписания
```bash
openbonch schedule
```

#### 4. Разовая отметка на доступных парах
```bash
openbonch checkin
```

#### 5. Запуск фонового демона автоотметки
Демон периодически опрашивает личный кабинет и автоматически отмечает вас, как только преподаватель открывает пару:
```bash
# Запуск с проверкой каждые 60 секунд:
openbonch watch --interval 60
```

#### 6. Выход и удаление локальной сессии
```bash
openbonch logout
```

## ⚖️ Юридическая чистота и лицензия

* Кодовая база создана с нуля методом «чистой комнаты» (Clean-Room Design) и распространяется под свободной лицензией **[MIT](LICENSE)**.
* Проект не использует код, графику или товарные знаки сторонних проприетарных сервисов.
* Расписание занятий на `sut.ru` является общедоступной информацией (ст. 1259 ГК РФ).
* Проект не собирает и не обрабатывает персональные данные на удаленных серверах (полное соответствие 152-ФЗ РФ).
