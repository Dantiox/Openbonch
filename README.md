# Openbonch

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![Language: Rust](https://img.shields.io/badge/Language-Rust-orange.svg)](https://www.rust-lang.org/)
[![Multiplatform](https://img.shields.io/badge/Platform-Linux%20%7C%20macOS%20%7C%20Android%20%7C%20FreeBSD%20%7C%20Windows-blue.svg)]()

**Openbonch** — полностью открытый и кроссплатформенный клиент расписания и локальной автоматизации для студентов СПбГУТ. 

Разработан как независимый локальный инструмент (Local-First) без коммерческих подписок, рекламы и передачи учетных данных на сторонние серверы.

---

## ✨ Ключевые возможности

* **100% Открытый исходный код (AGPLv3):** Свободное ПО для сообщества без платных подписок и скрытых пейволлов.
* **Приватность и Local-First:** Ваши учетные данные **НИКОГДА** не отправляются на сторонние серверы. Все запросы выполняются строго локально с вашего личного IP-адреса.
* **Авторизация по сессионному токену:** Поддерживается вход напрямую по cookie `miden` без ввода постоянного пароля.
* **Локальная автоматизация подтверждения занятий:** Мониторинг доступности интерактивных элементов в расписании и локальная синхронизация статуса.
* **Интерактивное расписание занятий:** Просмотр сетки занятий по дням недели, времени и аудиториям с быстрым подтверждением в один клик.
* **Навигатор кампуса:** Поэтажные схемы учебных корпусов с масштабированием жестами и поиском аудиторий.
* **Кроссплатформенное ядро:** Ядро `openbonch-core` написано на чистом Rust и компилируется под Linux, macOS Universal, Windows и Android.

## 📱 Android-приложение

Для Android разработано нативное приложение на **Jetpack Compose (Material 3)**:
* 📅 **Вкладка «Пары»:** Полный список занятий на неделю с временными шкалами и переходом на карту корпуса по клику на аудиторию.
* 🗺️ **Вкладка «Карта»:** Интерактивные схемы этажей с зумом пальцами и поиском кабинетов, столовых и деканатов.
* ⚡ **Вкладка «Автоматизация»:** Управление фоновой службой локальной синхронизации статуса (Foreground Service с Android KeyStore).
* 📜 **Вкладка «Журнал»:** Подробные логи локальных сетевых запросов для полной прозрачности.
* ⚙️ **Вкладка «Настройки»:** Выбор интервалов опроса, шифрование в Android KeyStore, вход по `miden` cookie без пароля.

Готовые сборки APK публикуются в разделе **[Releases](https://github.com/Dantiox/Openbonch/releases)**.

## 🚀 Быстрый старт (CLI)

### Сборка и установка из исходников
Требуется установленный тулчейн [Rust](https://rustup.rs/):

```bash
git clone https://github.com/Dantiox/Openbonch.git
cd Openbonch
cargo build --release
```
Исполняемый файл появится в `target/release/openbonch`.

### Команды CLI

#### 1. Авторизация
```bash
# Интерактивный вход по логину и паролю:
openbonch login

# Или вход напрямую по токену miden (без ввода пароля!):
openbonch login --token <ВАШ_MIDEN_COOKIE>
```

#### 2. Проверка статуса сессии
```bash
openbonch status
```

#### 3. Просмотр расписания
```bash
openbonch schedule
```

#### 4. Подтверждение доступных занятий в расписании
```bash
openbonch checkin
```

#### 5. Фоновый процесс локальной синхронизации
Процесс периодически опрашивает расписание и отправляет подтверждение при появлении активных элементов:
```bash
# Запуск с проверкой каждые 60 секунд:
openbonch watch --interval 60
```

#### 6. Выход и удаление локальной сессии
```bash
openbonch logout
```
