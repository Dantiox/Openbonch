# Openbonch Android Client

Нативный клиент расписания, навигатора кампуса и локальной синхронизации статуса событий для студентов на базе **Jetpack Compose (Material 3)**.

## 📱 Ключевые возможности

* 📅 **Расписание занятий:** Еженедельная сетка расписания (Понедельник — Суббота) с разбивкой по академическим парам, преподавателям и номерам аудиторий.
* 🗺️ **Интерактивный навигатор кампуса:** Поэтажные схемы учебных корпусов (пр. Большевиков к. 1 и 2, наб. реки Мойки, ВУЦ) с плавным жестом масштабирования (pinch-to-zoom), панорамированием и мгновенным поиском аудиторий. Все схемы рендерятся **локально офлайн на векторном Canvas**, без сторонних картографических сервисов и внешних сетевых тайлов.
* ⚡ **Локальная синхронизация статуса событий:** Мониторинг доступности интерактивных элементов в расписании и локальная отправка подтверждений в один клик либо через фоновую службу (Foreground Service).
* 🔒 **Local-First и аппаратное шифрование:** Учетные данные сохраняются строго в аппаратном Android KeyStore (`EncryptedSharedPreferences`, AES-256 GCM). Приложение не имеет собственных внешних серверов сбора данных.
* 🛡️ **Нулевая телеметрия и суверенитет сетевых потоков:** Полное отсутствие сторонних библиотек аналитики (Google Analytics, Firebase, Sentry, Crashlytics). Все сетевые обращения направляются напрямую и исключительно к официальному домену образовательного учреждения (`*.sut.ru`). Внешние или трансграничные вызовы аппаратно блокируются сетевым фильтром на системном уровне.
* 📶 **Аппаратный выбор сетевого маршрута:** Возможность принудительной маршрутизации запросов через физический Wi-Fi или сотовую сеть мобильного оператора в обход активного VPN-туннеля.

## 🛠️ Сборка из исходников

Требования: **JDK 17**, Android SDK (API 35, minSdk 26).

Сборка Debug APK:
```bash
cd android
./gradlew assembleDebug
```
Готовый установочный файл APK будет сгенерирован в каталоге `android/app/build/outputs/apk/debug/app-debug.apk`.
